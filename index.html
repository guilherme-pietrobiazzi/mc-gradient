Como aplicar o texto degradê RGB no seu servidor Minecraft

A partir da atualização Minecraft Java 1.16 (Nether Update), o jogo passou a suportar mais de 16 milhões de cores em formato hexadecimal. Utilize o formato adequado ao seu plugin ou arquivo:

Spigot / EssentialsX (&#RRGGBB)

Compatível com EssentialsX Chat, LuckPerms prefixes, TAB, DeluxeMenus e plugins modernos. Basta colar o código diretamente na configuração.

Legacy Hex (&x&R&R&G&G&B&B)

Sintaxe expandida nativa do BungeeCord/Spigot. Recomendada para plugins mais antigos que não convertem automaticamente a tag &#.

Paper / MiniMessage (<gradient>)

Sintaxe limpa e compacta usada nativamente pela API Adventure do PaperMC, Purpur e Velocity. Evita estourar o limite de caracteres do chat.

Server MOTD (\u00A7x...)

Formato Unicode pronto para ser colado diretamente após motd= dentro do arquivo server.properties do servidor.
